	\fld{Result} the flow this call adds from $s$ to $t$. Vertices $0..n$ are all usable.
	\fld{Needs} $s \ne t$ and capacities $\ge 0$, with \texttt{cap + rcap} plus the total flow below $9 \cdot 10^{18}$.

	\fld{sideS} \texttt{sideS(v)} is true on the source side of a min cut. K\"onig: left $v$ with it false and right $v$ with it true are a min vertex cover.
]\label{dinic}

\cpp[4]{Min-cost circulation (cost scaling)}{costscaling.hpp}[
	\fld{Use} \texttt{MinCostCirc mc(n + 1); int id = mc.addEdge(u, v, lo, hi, c); bool ok = mc.solve();}
	\fld{Result} \texttt{ok} is false if infeasible. \texttt{mc.total} (\texttt{\_\_int128}) is the min cost.
	\fld{Needs} $\texttt{lo} \le \texttt{hi}$, any signs, one \texttt{solve} per object. $N$ the constructor size: $4N(N + 1) \max |c|$, $\sum |\texttt{lo}|$, $\sum (\texttt{hi} - \texttt{lo})$ each $< 9 \cdot 10^{18}$.
	\fld{flowOf} \texttt{mc.flowOf(id)} is the flow on the edge. \texttt{mc.pot} are optimal duals: $c + \texttt{pot[u]} - \texttt{pot[v]} \ge 0$ on every arc with room.
	\fld{Models} \S\ref{flowmodels}
]\label{costscaling}
\entry{Flow models}\label{flowmodels}
{\small\tightdisplay
The graph has vertices $1..n$. Extra vertices are $S = n + 1$ and $T = n + 2$, so build \texttt{Dinic d(n + 3)}. Capacity $\infty$ is \texttt{oo}.
\topic{Lower bounds: feasible circulation}
Use it when every edge needs $l \le f \le r$ and there is no source or sink.
\begin{facts}
	\item Add the edge $u \to v$ with capacity $r - l$ and keep its \texttt{id}.
	\item Record the forced flow: $d_v \mathrel{+}= l$ and $d_u \mathrel{-}= l$.
	\item If $d_v > 0$, add $S \to v$ with capacity $d_v$.
	\item If $d_v < 0$, add $v \to T$ with capacity $-d_v$.
	\item A circulation exists if and only if
	\[ \texttt{maxFlow}(S, T) = \textstyle\sum_{d_v > 0} d_v. \]
	\item The flow on the edge is then $l + \texttt{flowOf(id)}$.
\end{facts}
Example: edge $u \to v$ with bounds $[2, 5]$: capacity 3, $d_v \mathrel{+}= 2$, $d_u \mathrel{-}= 2$.
\topic{Lower bounds with a source and a sink}
Use it for the largest or the smallest $s$--$t$ flow when edges have lower bounds.
\begin{facts}
	\item Add \texttt{ts = d.addEdge(t, s, oo)}, then build and test as in the topic above. The test also fails when every valid flow has a negative value.
	\item Let $f_0 = \texttt{flowOf(ts)}$, then delete that edge: \texttt{d.edges[ts].cap = d.edges[ts \symbol{94} 1].cap = 0}. The $S$ and $T$ edges may stay.
	\item Max flow: $f_0 + \texttt{maxFlow}(s, t)$.
	\item Min flow: $f_0 - \texttt{maxFlow}(t, s)$. A negative result is a net flow from $t$ to $s$.
	\item Each call changes the flow: build the network again to get the other one.
\end{facts}
Example: $s \to a$ with $[2, 4]$ and $a \to t$ with $[0, 3]$: max 3, min 2.
\topic{Min-cost circulation with negative cycles}
Use it with MCMF (\S\ref{mcmf}) when negative-cost edges may form a cycle, which MCMF cannot take.
\begin{facts}
	\item Add an edge with cost $c \ge 0$ as it is.
	\item Take an edge $u \to v$ with cost $c < 0$ and capacity $r$. Saturate it and pay $c \cdot r$ now.
	\item Add $v \to u$ with capacity $r$ and cost $-c$, to undo units.
	\item Record the saturation: $d_v \mathrel{+}= r$ and $d_u \mathrel{-}= r$.
	\item Add the $S$ and $T$ edges as in the first topic, with cost 0.
	\item Run \texttt{mf.maxFlow(S, T)}. The min cost is
	\[ \textstyle\sum_{c < 0} c \cdot r \; + \; \text{the MCMF cost}. \]
	\item Cost scaling (\S\ref{costscaling}) takes negative cycles and lower bounds directly.
\end{facts}
Example: edge $u \to v$ with capacity 4 and cost $-3$: pay $-12$, add $v \to u$ with capacity 4 and cost 3, $d_v \mathrel{+}= 4$, $d_u \mathrel{-}= 4$.
\topic{Fixed flow and supplies}
Use it when the $s$--$t$ flow must be exactly $F$, or a vertex must send out a net supply.
\begin{facts}
	\item MCMF: \texttt{auto [f, c] = mf.maxFlow(s, t, F);} is valid only if \texttt{f == F}.
	\item Cost scaling, fixed flow: \texttt{mc.addEdge(t, s, F, F, 0)}, then \texttt{mc.solve()}.
	\item Cost scaling, supplies: build \texttt{MinCostCirc mc(n + 2)} and let $X = n + 1$. For $b_v > 0$ add \texttt{mc.addEdge(X, v, b, b, 0)}. For $b_v < 0$ add \texttt{mc.addEdge(v, X, -b, -b, 0)}.
	\item \texttt{solve()} returns false when $\sum b_v \ne 0$ or no flow meets the supplies.
\end{facts}
Example: supply 3 at $u$ and demand 3 at $v$: edges $X \to u$ and $v \to X$, both with bounds $[3, 3]$.
\topic{Vertex capacities}
Use it when vertex $v$ lets at most $c_v$ units through.
\begin{facts}
	\item Split $v$ into $v_{in} = v$ and $v_{out} = v + n$.
	\item Now $S$ and $T$ move to $2n + 1$ and $2n + 2$, and the network has $2n + 3$ vertices: \texttt{Dinic d(2 * n + 3)}.
	\item Keeping $S = n + 1$ would merge it with $1_{out}$.
	\item Add $v_{in} \to v_{out}$ with capacity $c_v$, and $\infty$ for $s$ and $t$.
	\item An edge $u \to v$ becomes $u_{out} \to v_{in}$: \texttt{d.addEdge(u + n, v, cap)}.
	\item The answer is \texttt{d.maxFlow(s + n, t)}.
\end{facts}
Example: path $s \to a \to t$ with $c_a = 2$ and edge capacities 5: max flow 2.
\topic{Project selection (max-weight closure)}
Use it to choose a set with the largest total profit, where choosing one item can force choosing another.
\begin{facts}
	\item If $p_i > 0$, add $S \to i$ with capacity $p_i$.
	\item If $p_i < 0$, add $i \to T$ with capacity $-p_i$.
	\item For each rule ``$i$ needs $j$'' add $i \to j$ with capacity $\infty$.
	\item The best profit is
	\[ \textstyle\sum_{p_i > 0} p_i - \texttt{maxFlow}(S, T). \]
	\item The chosen set is the $i$ with \texttt{sideS(i)}.
\end{facts}
Example: $p_1 = 5$, $p_2 = -3$, 1 needs 2: max flow 3, best profit 2, set $\{1, 2\}$.
\topic{K\"onig and Dilworth}
Use it for covers of a bipartite graph, or for covering a DAG or a partial order with the fewest paths.
\begin{facts}
	\item Take a bipartite graph with $V$ vertices and max matching $M$.
	\item The min vertex cover has $M$ vertices, and the max independent set has $V - M$. Build the cover as in Dinic's note (\S\ref{dinic}).
	\item Split graph of a DAG: \texttt{Dinic d(2 * n + 3)}, $S = 2n + 1$, $T = 2n + 2$. Add $S \to u$ and $u + n \to T$ for each $u$, and $u \to v + n$ for each edge, all with capacity 1.
	\item Let $M = \texttt{maxFlow}(S, T)$.
	\item With the DAG's own edges, the fewest vertex-disjoint paths that cover all vertices number $n - M$. Path edges are the $u \to v + n$ with \texttt{flowOf} 1.
	\item With the edges of the transitive closure, the fewest chains number $n - M$. This equals the largest antichain (Dilworth).
	\item That antichain is the $v$ with \texttt{sideS(v)} and \texttt{!sideS(v + n)}, on the closure's network.
\end{facts}
Example: DAG $1 \to 2 \to 3$ plus vertex 4: $M = 2$, so 2 paths.
\topic{Hall's theorem}
Use it to prove that every left vertex can be matched, or to show why not.
\[ \text{a matching covers } L \iff |N(X)| \ge |X| \text{ for every } X \subseteq L \]
Here $L$ is the left side. $N(X)$ is the set of right neighbours of $X$.
\begin{facts}
	\item With $M < |L|$ on the matching network, the left vertices with \texttt{sideS} form a witness $X$:
	\[ |X| - |N(X)| = |L| - M. \]
\end{facts}
Example: two left vertices whose only neighbour is the same right vertex: $X$ is both, $|N(X)| = 1$.
}
\cpp[4]{Global min cut (Stoer--Wagner)}{stoerwagner.hpp}[
	\fld{Use} \texttt{auto [cut, side] = globalMinCut(g);} with \texttt{g[u]} $= \{v, w\}$, each edge in both lists.
